# 兼容性与验证边界

A/B 线协议版本为 1，仅支持明确协商的能力。构建产物记录 source_commit、gateway_version、protocol_version 和兼容范围；工作树构建含 `-dirty` 标记，发布时应使用已审核提交。

| 路径 | 实现要求与限制 |
| --- | --- |
| 原 direct | 开关关闭时保留原行为；历史网关绑定仍阻止从直连入口隐式抢占 |
| SIP | 设备侧 UDP/TCP，WSS 仅作载体；网关侧 SIP-TLS 不在 v1 范围 |
| RTP/UDP | 双向 RTP/RTCP、固定源校验、实际 RTCP 端点，不依赖 RTP+1 猜测媒体节点端口 |
| RTP/TCP | 主动/被动；需要 RFC4571 RTP/RTCP 复用能力 |
| 实时/回放/RTP 下载 | 复用现有国标业务入口和真实 ZLM 节点 |
| 语音与级联 | 各腿独立选 direct/对应 B，真实媒体节点连接 A 本地桥；上下级平台均使用独立平台绑定，平台通道计入通道数 |
| 裸 TCP 下载 | 原协议边界/长度/超时仍生效；网关桥显式传播 WSS 失败，不将中断当 EOF |
| 抓拍/升级 | B HTTPS 任务入口需设备信任相应 CA；设备最终升级结果仍由原 SIP 通知确认 |
| ZLM | 固定上游提交及 0001/0002/0003 三个补丁；缺少实际 RTCP 端口的节点会被拒绝 |
| 迁移 | 受限计划、旧业务排空、新 REGISTER 认证后原子提交；取消/过期不回滚已提交对象 |
| 出站代理 | 当前使用 A 直接拨号公网 WSS，`proxy_ref` 须为 null；预留引用非空会明确拒绝，不隐式使用环境代理 |

自动化检查覆盖源码、协议和宿主边界，不能替代公网网络、容器网络可达性和厂商设备验收。已按 Dockerfile 固定上游及三个补丁完成实际 ZLM C++ 构建；当前没有在真实公网部署本模块或宣称厂商互通通过。具体证据与限制见[开发交付记录](development.md)。
