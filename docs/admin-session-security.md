# 管理员凭据、会话与登录密钥

本次修改涉及管理员身份认证与 ONVIF 服务凭据。首次升级后所有管理员需重新登录，使用旧管理员账号连接 ONVIF 的客户端需改用独立 ONVIF 账号。

## 密码存储及启动迁移

- 管理员口令使用 PBKDF2-HMAC-SHA256、600,000 次迭代及 16 字节随机盐保存，不截断长口令。
- 启动时将主配置中的旧 `Server.Password` 转为 `Server.PasswordHash` 并清空明文；旧 `admin-credentials.toml` 原子迁移为 `Username`、`PasswordHash`、`SessionVersion`。文件保留在原目录，新写入文件权限为 `0600`。
- 网页保存的凭据仍优先于部署环境变量。环境变量初始化的口令仅转换为运行时哈希，不在此次启动迁移中将环境变量明文或哈希写入主配置。环境变量应继续由原部署系统管理。
- 新部署如果既无有效哈希、旧口令，也无已保存凭据，必须设置 `OWL_ADMIN_PASSWORD`（至少 8 字节且不能是已公开示例口令）。不会生成一个只能看到哈希、无人知道原文的随机管理员密码。
- 哈希损坏或迁移写入失败时启动报错；不会回退到旧密码继续提供服务。网页改密先原子保存哈希与新会话版本，成功后再更新内存；保存失败不改变当前口令和会话。

迁移只处理当前配置及凭据文件，不删除已有备份、环境变量、历史日志或仓库历史里的口令。恢复备份时应同步恢复主配置与凭据文件；旧版本不识别新哈希格式，不能直接只回滚二进制。恢复旧凭据文件可能恢复旧会话版本，恢复后应再次改密。

## 会话撤销范围

管理员登录 JWT 保持 3 天有效期，新增会话版本校验。用户名或密码保存成功后，即使用户名未变、同一秒内改密，所有旧管理员令牌也会失效；版本与新口令一同持久化，重启不会复活旧令牌。

校验覆盖普通 API（含 URL 中的旧管理令牌）、升级管理、开放平台管理、接入网关、pprof 和通知 WebSocket。改密会关闭旧通知 WebSocket Hub，包括其中正在鉴权的连接；新登录后可重新连接。

通过平台播放代理签发的直播/回放令牌同样携带版本，改密后旧链接的新请求会被拒绝。已经通过鉴权的在途 HTTP 请求、已建立的媒体流及 WebRTC 会话不会被强制终止；直连媒体服务器的 RTSP/RTMP 地址和开放平台独立应用凭据不属于管理员 JWT 会话。

第三方 `AuthURL` 继续负责它自己签发的凭据。有效签名的本平台令牌一旦过期或被撤销，会直接拒绝，不再尝试第三方放行。管理员改密不撤销第三方账号或开放平台应用密钥。

## ONVIF 独立凭据

ONVIF 的 WS-Security PasswordDigest 必须使用原始协议密码，无法用管理员单向哈希替代，因此现在使用独立配置：

```toml
[Server.ONVIF]
Username = 'owl-onvif'
Password = '' # 首次启动生成随机值并保存；不复制管理员口令
```

可用 `OWL_ONVIF_USERNAME`、`OWL_ONVIF_PASSWORD` 覆盖。运行账号可在主配置中读取自动生成的 ONVIF 凭据；为 Home Assistant 等客户端更新用户名和密码。独立密码只供 ONVIF 使用，管理员改密不会改变它，修改独立配置后需重启。未配置完整 ONVIF 凭据的嵌入式调用会拒绝访问。

## 登录 RSA 密钥轮换

登录及改密仍提交 RSA-OAEP/SHA-256 密文。`GET /login/key` 保留 `key`、`oaep_seed`，新增 `key_id`；管理端将 `key_id` 随 `data` 一起提交。响应禁止缓存。

公钥有效期 1 小时，轮换后只保留上一把私钥，宽限截止时间为旧公钥到期后 5 分钟；空闲期间不轮换也不会无限延长密钥接受期限。新客户端按 `key_id` 精确匹配；旧客户端不传 ID 时在同一宽限内尝试当前及上一把密钥。超时或服务重启后，客户端需重新获取公钥再提交。

## 发布后人工确认

1. 旧管理员密码可正常登录；改密后另一标签页的旧令牌和旧播放链接失效，新密码可登录，重启后结果一致。
2. 使用新独立凭据连接 ONVIF，确认发现、媒体地址获取正常；旧管理员凭据不能用于 ONVIF。
3. 改密后通知连接断开，重新登录可以恢复通知；采集 pprof 时换用新登录令牌。
