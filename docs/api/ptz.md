# 云台控制与信令探测

`POST /channels/{id}/ptz` 下发控制指令，例如：

```json
{"action":"right","speed":30,"timeout":1}
```

GB28181 的 `timeout` 是连续方向、变倍、聚焦和光圈动作的执行秒数；默认 6 秒，通道页默认 1 秒，可选择 1、2、3、5、10 秒，实时监控页使用 1 秒。到期后服务端发送对应停止指令，HTTP 请求结束不会取消这次停止。新的移动或停止命令替换旧的停止任务，级联接管会取消旧任务。预置位设置、辅助开关等一次性动作不执行自动停止。开放平台继续使用原有租约停止调度。

通道页将八方向、停止、变倍、聚焦、光圈、速度和预置位放在常用区；高级区折叠展示巡航、扫描、辅助开关、看守位和精准定位。巡航、扫描须分别手动停止，不使用点动时长。设置预置位会覆盖该编号的原位置，辅助开关编号以设备说明为准。

四版本国标均可下发基础 PTZCmd（包括预置位、巡航、扫描和辅助开关）；看守位需 2016/2022，精准定位需 2022，且遵循设备的有效扩展能力声明。不支持的入口保留并禁用，悬停显示具体原因；设备未声明硬件云台能力时仍可试控。

ONVIF 当前适配器支持方向、变倍、光圈与预置位，方向和变倍固定点动 1 秒。聚焦尚缺少自动停止，通道页暂时禁用；巡航、扫描、辅助开关、看守及精准定位暂未通过该接入实现，悬停提示适配限制，不将其误报为 ONVIF 协议本身不支持。实际硬件是否支持操作仍以设备应答和现场观察为准。

控制接口成功只表示设备返回 SIP 成功应答。是否实际转动，需要观察视频或在录像机本机确认，不能由 SIP 200 推断。

`POST /channels/{id}/ptz_probe` 仅允许 `stop` 或省略动作，检查停止信令连通性：

```json
{
  "channel_id":"chfio0b",
  "ptz_capable":false,
  "ptz_verified":false,
  "verified_now":false,
  "signaling_ok":true,
  "message":"设备已接受停止信令，实际云台能力仍需观察画面确认"
}
```

- `ptz_capable` 表示设备声明的能力，未知时为 false，不阻止支持该协议的通道手动试控。
- `signaling_ok` 表示本次信令是否收到成功应答；失败原因见 `message`。
- `ptz_verified`、`verified_now` 为兼容旧客户端保留，均返回 false。历史停止探测产生的验证标记不再作为能力依据，无需数据库迁移。
- 设备批量探测的 `success_count`、`failed_count` 按信令应答统计，不代表实际转动验证。

排障时按应用日志的 `device_id`、`channel_id`、`action`、`ptz_cmd`、`sn` 关联下发与 SIP 确认；自动停止失败会单独记录警告。若信令成功但画面不动，优先比较同一通道在录像机本机上的控制结果，再检查录像机的国标云台转发与摄像头配置。
