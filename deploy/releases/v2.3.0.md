# v2.3.0 媒体节点只读管理

目标服务器：`10.144.0.20` / `192.168.6.20`，运行目录 `/www2/gowvp-v1`。前一版本为 `v2.2.3`，本版本统一纳入当前工作树全部应用源码，服务版本和镜像标签均为 `v2.3.0`。

新增媒体节点六分区：概览、媒体流、网络会话、RTP 服务、代理任务与运行诊断。后端接入 14 类只读查询，支持单路媒体与观看连接、RTP 接收信息；前端提供完整快照搜索、分类过滤、分页、原始字段展开、独立刷新及可选 15 秒自动刷新。不提供 ZLM 配置编辑、重启、断流或任务增删。响应隐藏连接凭据，明确区分查询成功空集、版本不支持与查询失败。

与 `v2.2.3` 固定源码快照对比，此次应用变更为媒体节点功能；此前 PTZ、录像工作区、播放器、推流状态、侧栏与水印开关修复均已在现网版本内，本轮同步纳入 Git。接口与数据口径见 [媒体节点只读巡检](../../docs/api/media-nodes.md)。

发布前检查：63 项前端测试及媒体查询、PTZ、历史回放与通道推流状态的相关 Go 回归通过。发布使用固定源码归档构建 Linux/amd64 后端和同源前端，以现网应用镜像为基础覆盖全部应用产物，保留旧哈希静态资源。只重建 GoWVP；配置、PG 和 ZLM 版本保持，无新增数据库迁移。

发布时先完成配置及 PostgreSQL 在线一致性备份并检查 `pg_restore --list`，持发布互斥锁；失败恢复原环境文件和应用镜像。构建与上线核验结果在发布完成后补充。

回滚到 `v2.2.3`：

```bash
cd /www2/gowvp-v1
cp -a backups/before-v2.3.0-20261105/.env .env
docker compose -p owl-v1 --env-file .env -f docker-compose.yml \
  up -d --no-deps --no-build --pull never --wait --wait-timeout 180 gowvp
curl -fsS http://127.0.0.1:15123/health
```

配置与数据库备份含凭据，仅在服务器受限目录保存，不提交 Git。界面和真实设备业务由人工验收，不以只读接口检查代替真实视频与云台验收。
